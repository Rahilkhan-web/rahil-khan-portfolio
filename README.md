# Rahil Khan Portfolio Website

A responsive static portfolio website built with:
- HTML5
- CSS3
- Vanilla JavaScript

## Run locally
Open `index.html` in a browser.

## Free hosting

1. GitHub Pages

3. Cloudflare Pages

## Before publishing
- Add your LinkedIn URL if desired.
- Add a GitHub URL if desired.
- Replace the initials card with a professional photo only if you want one.
- Review your contact details before publishing.
